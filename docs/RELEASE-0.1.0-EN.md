## Oracle OS 0.1.0 + GENESIS 0.1.0

**Install (Android 8+):** download `OracleOS.apk` and tap it to install. For the game, `GENESIS.apk`. Switch Oracle to English with **EN** at the top right of Home; in GENESIS tap **English** on the first screen.

| File | What for |
|---|---|
| [`OracleOS.apk`](https://github.com/caiorlm/oracle-os/releases/latest/download/OracleOS.apk) | The app: built-in guides, compass, plants, maps, power saving, emergency, Game tab |
| [`GENESIS.apk`](https://github.com/caiorlm/oracle-os/releases/latest/download/GENESIS.apk) | The game (farm, companion, lineage) — opens from the GAME tab |
| [`Qwen3.5-0.8B-Q4_K_M.gguf`](https://github.com/caiorlm/oracle-os/releases/latest/download/Qwen3.5-0.8B-Q4_K_M.gguf) | Local AI (optional, 508 MB): System → Import GGUF |
| `Oracle-Print-EN.pdf` | Every guide, ready to print on A4 |
| `SHA256SUMS.txt` | Checksums to verify the files |

The links above point to the same files on the main release ([caiorlm/oracle-os](https://github.com/caiorlm/oracle-os/releases/latest)); it is the same app — switch the language inside it.

New: low-poly 3D animated intro, extreme power saving, print pack, library tree, 71 EN/PT guides (including childbirth, seeds, animals, crafts, basic chemistry, natural building, communication without power, calendar, community) and the GENESIS game.

APKs are signed with a development key (first release). Works without internet once installed.
